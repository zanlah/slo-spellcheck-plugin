# Dictionary files

## sl.dawg

A minimised word automaton (format: `scripts/dawg-encode.mjs`) with about 3.3 million Slovene
word forms and a corpus-frequency class for each. Generated by `npm run build:dict`. Don't edit it by hand.

Sources:

- **Sloleks 3.1**, the morphological lexicon of Slovene. Čibej, Jaka et al., Centre for Language
  Resources and Technologies, University of Ljubljana, 2026. http://hdl.handle.net/11356/2080.
  Licensed under CC BY-SA 4.0. The build keeps standard and variant orthographic forms with their
  Gigafida 2.0 frequencies. It skips forms marked `non-standard`, and automatically generated proper
  nouns that look like corpus typos of a much more frequent name (for example "Ljubljna").
- **LibreOffice Slovenian dictionary (sl_SI, Hunspell)**, via the `dictionary-sl` npm package.
  Licensed under GPL-3.0 OR LGPL-2.1. Every form accepted by the Hunspell dictionary is included.

This file is an adaptation of Sloleks (CC BY-SA 4.0) combined with the GPL-3.0/LGPL-2.1 Hunspell
word list. CC BY-SA 4.0 is one-way compatible with GPL-3.0, so `sl.dawg` is distributed under
GPL-3.0, with the attribution above. The add-in source code remains MIT.

## custom.dic

Extra words accepted on top of `sl.dawg`, one per line (`#` starts a comment).
